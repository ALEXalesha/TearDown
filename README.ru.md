# VoxelBreak

**В планах.** Песочница разрушения в браузере: мир из маленьких кубиков, где всё ломается по-настоящему, по кусочкам,
а обломки падают по физике. В духе игры Teardown, но своё и для веба.

работа. Это другой проект, не [TeardownMods](https://github.com/ALEXalesha/TeardownMods) (моды для настоящей игры).

## Что будет

- **Чем ломать:** молот и руки (отбивать по кусочку, толкать обломки), взрывы (динамит, бочки, цепная реакция), оружие
  (дробовик, ракетница, лазер), техника (таранить машиной, бульдозер, кран с шаром).
- **Мир:** город (дома, заборы, машины, столбы), природа (деревья, скалы, мосты) и **случайный мир** - каждый раз новая
  карта кодом.
- **Честное разрушение:** оторванный кусок становится отдельным телом и падает; конструкция без опоры рушится. Никакой
  подмены модели на заранее сломанную.
- **Бюджет кадра:** большой взрыв не должен ронять игру до неиграбельных к/с - мелкие обломки объединяются, неподвижные
  засыпают.

Пока не планируется: сюжет, миссии, противники, мультиплеер.

## Как будет устроено

- Браузер и Хаб, three.js с воксельными чанками и жадным мешингом, своя физика обломков (или Rapier в WASM), своя
  программа на Electron; GitHub Pages.
- Из прошлых работ берутся идеи, а не код: моды Teardown (катапульта, цунами, чёрная дыра) и игра «Кубический мир».
- Русский и английский, тесты без видимых окон.
- Законы (автоматические проверки): кусок без опоры падает, взрыв радиуса R убирает ожидаемое, 60 к/с на эталонной сцене.
